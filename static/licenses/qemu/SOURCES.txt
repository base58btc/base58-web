Local changes: static/js/course-qemu-memory.mjs lowers the fixed memory import minimum to 1536 MiB. No guest checkpoint or user VM state is distributed or saved. The guest boots from its kernel and initramfs. The command transport and course filesystem integration are in static/js/course-qemu-worker.js and static/guest/course-qemu.py.
